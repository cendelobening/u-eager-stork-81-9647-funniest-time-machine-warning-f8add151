A one-line warning label for a time machine, written like a genuine safety
notice — because the first person to ignore it was already you:

> WARNING: Your past self read this label and ignored it. So will you.

The joke is the paradox itself: the label warns you about a mistake your
past self has already made, and the punchline lands on the reader, who is
about to make it again. `main.py` (pure Python standard library) validates
the line — 1–120 characters, single line, no control characters — and writes
it to `entry.txt` with no trailing newline.

## Run it

```sh
python3 main.py
# or, to choose where entry.txt goes:
MAKEFUN_OUTPUT_DIR=/tmp/test-time-machine python3 main.py
```
